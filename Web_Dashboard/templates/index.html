Open Day Project Guide & How It Works

Project Documentation
⏱️

1. Hardware Timer Latency Measurement

In safety-critical robotics and automotive systems, predictable latency is paramount. Here, STM32's hardware timer TIM2 is configured with a 32 MHz prescaler to tick once every microsecond. It records t_REQUEST right before clocking out the SPI packet, and records t_ACK the moment the slave returns 'A','C','K'. The difference gives the true hardware Round-Trip Time ($RTT$).

🛡️

2. Fault Detection & Automatic Recovery

The equipment node and monitoring node maintain a 500 ms heartbeat cadence. If a wire is severed or a node resets, the ESP32 gateway notices the silence. If no heartbeat arrives for > 2000 ms, the system enters FAULT mode and logs the event. Once the connection is reconnected, the very next valid packet triggers RECOVERED, restoring operations smoothly.

📡

3. Wireless Gateway & Web Dashboard

Instead of needing a debug cable plugged into a PC, the ESP32 acts as a standalone wireless gateway. It listens to the STM32 via high-speed UART (115200 baud), calculates statistics like jitter and packet loss, and streams JSON data over Wi-Fi directly to this live web interface.
